# Project Overview

## Background
Northstar is a fictional policy administration application for a demo insurance carrier.

## Problem statement
Teams need a consistent way to document expected behavior, track testing work, and record defects across policy workflows.

## Objectives
- Make project information easy for technical and nontechnical stakeholders to find.
- Keep requirements linked to test coverage and defects.
- Make progress visible without requiring stakeholders to inspect source code.

## In scope
- Quote creation
- Policy issuance
- Renewal eligibility
- Role-based access checks

## Out of scope
- Real carrier integrations
- Real customer information
- Production deployments
- Payment processing

## Success criteria
- Each demo requirement has acceptance criteria.
- Each sample workflow has at least one test scenario.
- Demo issues have an owner, priority, and status.
