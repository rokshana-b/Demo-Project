# Northstar Insurance QA Demo

> Fictional project content for demonstrating GitHub documentation and project management. No real customer or company data is included.

## Project overview
Northstar is a fictional insurance platform used to demonstrate policy administration QA workflows.

## Demo goals
- Organize project documentation in one repository.
- Track work through GitHub Issues and Projects.
- Demonstrate user stories, acceptance criteria, defects, and test scenarios.
- Show how documentation can evolve alongside the project.

## Current demo scope
- Fictional states: Maple, Cedar, and Harbor
- Fictional roles: Underwriter, Service Representative, QA Analyst
- Fictional workflows: create a quote, issue a policy, renew a policy

## Repository guide
- `docs/` — project overview and glossary
- `requirements/` — sample requirements and user stories
- `test-plans/` — sample QA approach
- `test-cases/` — manual test scenarios
- `test-data/` — fictional reference data
- `reports/` — sample test summary
- `.github/ISSUE_TEMPLATE/` — issue templates

## Suggested GitHub demo
1. Open an issue from a user story or defect.
2. Add labels such as `type: bug`, `priority: high`, or `area: policy`.
3. Add issues to a GitHub Project board.
4. Move cards through `Backlog`, `Ready`, `In Progress`, `In Review`, and `Done`.
5. Create a milestone called `Demo Release 1`.
6. Link a pull request or documentation change to an issue.

## Disclaimer
All names, requirements, data, and scenarios in this repository are invented for demonstration purposes.
