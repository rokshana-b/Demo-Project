# Project brief: Harborlight Auto Quote Pilot

**Project code:** HARBOR-QA-DEMO  
**Status:** Planning sample  
**Demo window:** 2026-11-02 to 2026-11-20 (fictional)

## Purpose

Show how a small QA project can keep its requirements, test planning, sample evidence, and work tracking together in GitHub. The business scenario is an invented personal auto quote flow.

## Demo objectives

- Capture a few clear, reviewable requirements and user stories.
- Track delivery work and defects as GitHub Issues.
- Use labels, milestones, and a Project board to show progress.
- Keep test cases and a simple execution summary beside the project documentation.

## In scope

- Quote form validation and premium estimate display.
- Two fictional discount rules.
- Manual testing and issue triage.
- Documentation and sample data organization.

## Out of scope

- A working quote application, real integrations, payment, underwriting, or claims.
- Automated tests, deployment workflows, or production readiness.
- Real customer, employee, carrier, or policy data.

## Fictional roles

| Role | Demo responsibility |
|---|---|
| Product owner | Confirms the sample stories and priorities |
| QA lead | Maintains test scope and summarizes results |
| Tester | Runs manual scenarios and records evidence |
| Developer | Reviews and resolves demo defect issues |
