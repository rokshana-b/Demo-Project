# Glossary

| Term | Demo meaning |
|---|---|
| Quote | An indicative estimate before a policy is issued |
| Garaging ZIP | Fictional five-digit location input used by the quote form |
| Safe-driver discount | Sample reduction when the driver meets the demo rule |
| Multi-vehicle discount | Sample reduction when two or more vehicles are entered |
| Acceptance criteria | Conditions that show a user story is complete |
| Traceability | A link between a requirement, test case, and result |

All rules are invented for this sample project.
