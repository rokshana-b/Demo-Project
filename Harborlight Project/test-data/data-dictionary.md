# Sample data dictionary

| Field | Meaning | Example |
|---|---|---|
| `scenario_id` | Fabricated reference for a test row | `HL-1001` |
| `garaging_zip` | Fictional five-character ZIP-like input | `00000` |
| `driver_dob` | Invented date of birth in ISO format | `1988-04-12` |
| `vehicles_count` | Number of sample vehicles on quote | `2` |
| `safe_driver_eligible` | Whether the made-up safe-driver rule applies | `true` |

These values are intentionally generic and must not be treated as real policyholder data.
