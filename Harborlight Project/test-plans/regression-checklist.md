# Regression checklist

Use this short checklist after a change to the sample quote flow. Mark each item in a copy of this file or record the result in the report.

- [ ] Valid quote produces an estimate and reference (TC-001).
- [ ] Missing required value shows a helpful prompt (TC-002 / TC-003).
- [ ] Eligible safe-driver discount appears once (TC-004).
- [ ] Eligible multi-vehicle discount appears once (TC-005).
- [ ] Accepted document type and size are handled (TC-006).
- [ ] Unsupported or oversized document is rejected clearly (TC-007).
- [ ] Review screen shows submitted details (TC-008).
